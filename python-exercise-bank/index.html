列表编程题基础

三种方式删除元素

已有 tasks = ["预习", "听课", "练习", "复习"]。依次：用 del 删除第一项；用 pop() 删除并保存最后一项；用 remove() 删除 "练习"。输出最终列表和被 pop() 删除的内容。

参考答案答案不唯一，仅供参考
tasks = ["预习", "听课", "练习", "复习"]

del tasks[0]                 # 按索引删除，不返回元素
last_task = tasks.pop()       # 删除末尾元素并返回它
tasks.remove("练习")          # 按值删除，不返回元素

print(tasks)                  # ['听课']
print(last_task)              # 复习

列表编程题进阶

比较永久排序与临时排序

给定 cities = ["Tokyo", "Shanghai", "Berlin", "Paris"]。先按字母顺序临时显示，再显示原列表，最后按字母倒序永久修改原列表并输出。

参考答案答案不唯一，仅供参考
cities = ["Tokyo", "Shanghai", "Berlin", "Paris"]

print(sorted(cities))               # 临时排序，不改变原列表
print(cities)                       # 原顺序保持不变

cities.sort(reverse=True)           # 永久修改为字母倒序
print(cities)

列表编程题进阶

切片并复制列表

给定 scores = [72, 85, 91, 68, 88, 95]。输出前三个成绩和最后两个成绩，再创建一份完整副本 backup。修改原列表的第一个成绩为 100，并证明 backup 没有改变。

参考答案答案不唯一，仅供参考
scores = [72, 85, 91, 68, 88, 95]

print(scores[:3])   # 前三个：[72, 85, 91]
print(scores[-2:])  # 后两个：[88, 95]

backup = scores[:]  # 切片产生一个新的列表
scores[0] = 100

print(scores)       # 第一个元素已改变
print(backup)       # 副本仍以 72 开头
