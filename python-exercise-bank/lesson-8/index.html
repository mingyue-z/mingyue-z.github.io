用类管理图书借阅状态

定义 Book 类，属性包括 title、available（默认True）和 borrower（默认None）；borrow(name) 在可借时登记借阅人，否则给出提示；return_book() 恢复可借状态。创建两本书，依次完成借阅、重复借阅、归还操作，最后遍历对象列表输出每本书的状态。 程序使用以下初始数据： books=[Book("Python入门"),Book("算法基础")]

参考答案答案不唯一，仅供参考
# 一种参考写法
class Book:
    def __init__(self,title):
        self.title=title
        self.available=True
        self.borrower=None
    def borrow(self,name):
        if not self.available:
            return "已被借出"
        self.available=False
        self.borrower=name
        return "借阅成功"
    def return_book(self):
        self.available=True
        self.borrower=None
    def status(self):
        return self.title+("：可借" if self.available else "：借给"+self.borrower)
books=[Book("Python入门"),Book("算法基础")]
print(books[0].borrow("李华"))
print(books[0].borrow("王明"))
books[0].return_book()
for book in books:
    print(book.status())

# 一种参考写法
class Course:
    def __init__(self,name):
        self.name=name
        self.students=[]
    def enroll(self,name):
        if name not in self.students:
            self.students.append(name)
class OnlineCourse(Course):
    def __init__(self,name,platform):
        super().__init__(name)
        self.platform=platform
    def fee(self):
        return len(self.students)*100

定义 Product 类保存 name、price、stock；定义 Cart 类，把多个“商品对象和购买数量”保存为列表。Cart.add() 必须检查数量为正且库存足够，checkout() 计算总额并扣减库存。使用两件商品测试成功加入和库存不足两种情况，输出结算金额及剩余库存。 请从下面的初始数据开始： book=Product("书",45,3) pen=Product("笔",6,2) cart=Cart()

class Product:
    def __init__(self,name,price,stock):
        self.name=name
        self.price=price
        self.stock=stock
class Cart:
    def __init__(self):
        self.items=[]
    def add(self,product,quantity):
        if quantity<=0 or quantity>product.stock:
            return "数量无效"
        self.items.append((product,quantity))
        return "已加入"
    def checkout(self):
        total=0
        for product,quantity in self.items:
            total+=product.price*quantity
            product.stock-=quantity
        self.items.clear()
        return total

为成绩类实现数据验证和统计

定义 Student 类，初始化姓名和成绩列表。add_score(score) 只接受0—100的数字；average() 返回平均分，没有成绩时返回0；level() 根据平均分返回A、B、C或D。创建三名学生，加入包含无效值的成绩，逐名输出有效成绩、平均分和等级。 程序使用以下初始数据： students=[Student("甲"),Student("乙"),Student("丙")]

参考答案答案不唯一，仅供参考
# 一种参考写法
class Student:
    def __init__(self,name):
        self.name=name
        self.scores=[]
    def add_score(self,score):
        if isinstance(score,(int,float)) and 0<=score<=100:
            self.scores.append(score)
    def average(self):
        return sum(self.scores)/len(self.scores) if self.scores else 0
    def level(self):
        avg=self.average()
        if avg>=90:
            return "A"
        if avg>=80:
            return "B"
        if avg>=60:
            return "C"
        return "D"
students=[Student("甲"),Student("乙"),Student("丙")]
for student,data in zip(students,[[90,95,120],[78,82],[55,58]]):
    for score in data:
        student.add_score(score)
    print(student.name,student.scores,student.average(),student.level())

# 一种参考写法
class Restaurant:
    def __init__(self,name):
        self.name=name
        self.served=0
    def set_served(self,n):
        self.served=max(0,n)
    def increment_served(self,n):
        if n>0:
            self.served+=n
    def describe(self):
        return f"{self.name} 已服务 {self.served} 人"
class IceCreamStand(Restaurant):
    def __init__(self,name,flavors):
        super().__init__(name)
        self.flavors=flavors
    def show_flavors(self):
        return ",".join(self.flavors)

shop.increment_served(8)

print(shop.describe())
print(shop.show_flavors())

在 student.py 中定义 Student 类，保存姓名和成绩并计算平均分；在 classroom.py 中导入 Student，定义 Classroom 类，能够添加学生并返回平均分最高的学生；在 main.py 创建三名学生并输出最高者。参考答案分别展示三个文件的内容。 程序使用以下初始数据： room=Classroom() top=room.top_student()

参考答案答案不唯一，仅供参考
# 一种参考写法
# student.py
class Student:
    def __init__(self,name,scores):
        self.name=name
        self.scores=scores
    def average(self):
        return sum(self.scores)/len(self.scores)
# classroom.py
from student import Student
class Classroom:
    def __init__(self):
        self.students=[]
    def add(self,student):
        self.students.append(student)
    def top_student(self):
        return max(self.students,key=lambda s:s.average())
# main.py
from student import Student
from classroom import Classroom
room=Classroom()
for student in [Student("甲",[80,90]),Student("乙",[95,92]),Student("丙",[88,87])]:
    room.add(student)
top=room.top_student()
print(top.name,top.average())

使用对象列表完成车辆续航报告

定义 Battery 类，根据容量60或85返回续航里程240或270；定义 Car 类保存品牌和型号；ElectricCar 继承 Car，并把 Battery 对象作为属性。创建不同电池容量的两辆电动车，循环输出品牌、型号、电池容量和续航里程。 开始编程前，先建立以下数据： cars=[ElectricCar("Tesla","Model 3",60),ElectricCar("BYD","Han",85)]

参考答案答案不唯一，仅供参考
# 一种参考写法
class Battery:
    def __init__(self,size=60):
        self.size=size
    def range(self):
        return 240 if self.size==60 else 270
class Car:
    def __init__(self,brand,model):
        self.brand=brand
        self.model=model
class ElectricCar(Car):
    def __init__(self,brand,model,size):
        super().__init__(brand,model)
        self.battery=Battery(size)
cars=[ElectricCar("Tesla","Model 3",60),ElectricCar("BYD","Han",85)]
for car in cars:
    print(car.brand,car.model,car.battery.size,car.battery.range())

使用 property 控制属性

定义 Score 类，把实际数据保存在 _v 中，并用 @property 提供只读的 value 属性。创建 Score(90)，以 score.value 的形式读取并输出90。

# 一种参考写法
class Score:
    def __init__(self,v):
        self._v=v
    @property
    def value(self):
        return self._v
print(Score(90).value)
